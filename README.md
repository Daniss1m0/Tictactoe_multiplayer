# Tictactoe Multiplayer

Projekt stanowi **klientską wersję gry „Kółko i Krzyżyk” (TicTacToe)** napisaną w języku **Java** z użyciem biblioteki **JavaFX**. Gra została rozbudowana o możliwość rozgrywki wieloosobowej (multiplayer) przy użyciu serwera (dostępny w oddzielnym repozytorium).

## Zrealizowane funkcjonalności

* Interfejs graficzny zbudowany w JavaFX
* Obsługa gry w trybie multiplayer (połączenie klient–serwer)
* Walidacja ruchów gracza i reguł gry
* Wyświetlanie zwycięzcy / remisu
* Możliwość restartu gry po zakończeniu rundy

Wersja serwera dostępna pod adresem: [Tictactoe_multiplayer_Server](https://github.com/Daniss1m0/Tictactoe_multiplayer_Server)
